Courses by author

Seven groups, one design problem each

Courses are grouped so each author faces one kind of problem and one subject voice, and so courses a student moves through in sequence are written by the same hand. Open a group to see each course, its catalog commitments, and its issues. A red dot marks a course with a red flag.

1 · Backend & full-stack projects

3 courses · ≈ 100 lessons · first deadline 12 Oct 2026
BE105 Advanced Backend Concepts and MicroservicesBE106 Backend ProjectFE103 Frontend Integration Project

Why together. All three are two-lane project courses with Flask or React work outside Maestro. One owner applies the pattern first, and the capstone author reuses it. Needs the team's Flask expert.

BE105

Advanced Backend Concepts and Microservices (Flask)

SWE core · Term 64 credits · 4 unitsNeeded by 12 Oct 2026

Catalog commits to: organising large-scale Flask projects, configuration management, Flask extensions for scalability, asynchronous programming concepts, asyncio and async/await, microservices.

  • GuidelineFlask is binding. The catalog name says Flask, so the backend is Flask, not FastAPI or Express.
  • GuidelineSplit by lane. Project layout, extensions and the microservices build go in the project lane in VS Code. asyncio and async/await drills fit the Python editor as topic lessons.
  • GuidelineArchitecture diagrams are drawn in an external tool the tutor cannot see. The lesson asks the student to describe services and their boundaries in chat; put the diagram on a discussion-board slot.
BE106

Backend Project

SWE project · Term 65 credits · 4 unitsNeeded by 23 Nov 2026

Catalog commits to: students build their own end-to-end backend with an authentication system, user management, CRUD operations, Docker deployment, and version control.

  • Red flagNo project submission. The course is the project, and the only way to grade it today is a link pasted into an open-text question in the final exam, checked manually by an instructor. That is a workaround, not a solution: there is no place to state the project requirements clearly, and submitting a build inside a timed exam event is confusing for the student. Until a submission feature exists, write the requirements into a dedicated project lesson, and make the submission a repo link plus a demo video with the live URL optional.
  • GuidelineDocker, git and deploy are taught as topic lessons and done in the project lane, deploying to Hugging Face Spaces or Render (no card needed). The last project step is recording the demo: container start, deployed URL responding, short code walkthrough. During lessons the tutor cannot open links, so the student pastes container logs, git log output, or the curl response; the repo and the video only reach a human, through a discussion-board slot or the final.
  • GuidelineMostly project lane. Keep a few topic lessons per unit (auth review, Docker basics, git workflow) so reviews have something to test, and restate the project state in every step.
FE103

Frontend Integration Project (Full-stack connectivity, frontend-focused)

SWE project · Term 85 credits · 4 unitsNeeded by 3 May 2027

Catalog commits to: choosing an application domain and scope, user stories and acceptance criteria, wireframes and UI mockups, mapping backend API endpoints and data flows, planning authentication and authorization flows.

  • Red flagNo project submission. Same as BE106: links in the final exam are the only route today, with no clear place for requirements and an awkward fit inside a timed exam. Submission is repo plus demo video; the frontend deploys to Vercel or Netlify, and the video shows it calling the live backend.
  • GuidelineA real backend is binding. The React app must talk to a live API, not mock data. The tutor will not remember the student's BE106 backend, so ship a reference API contract in the syllabus that any student can build against, and let students substitute their own.
  • GuidelineWireframes and mockups go in an external tool. Describe them in chat, and give the wireframe a discussion-board slot so an instructor sees it.
  • GuidelineReact builds run outside. The web editor is for static HTML, CSS and JS drills only.

2 · AI sequence

4 courses · ≈ 130 lessons · first deadline 4 Jan 2027
AI101 Introduction to AI Concepts & Math FoundationsAI102 Fundamentals of Machine LearningAI103 Prompt Engineering & Working with LLMsAI104 Applied AI Capstone Project

Why together. The full prerequisite chain from AI concepts to ML to LLMs to capstone, one voice throughout, and the same VS Code workflow because the Python editor has no ML libraries. AI104 is written last and borrows the Backend group's project convention. AI101's math-notation red flag is shared with the math group, so borrow whatever partial answer that author finds.

AI101

Introduction to AI Concepts & Math Foundations

SWE core · Term 74 credits · 4 unitsNeeded by 4 Jan 2027

Catalog commits to: what artificial intelligence is, a brief history, symbolic vs statistical AI, general vs narrow AI, ethics and societal impacts, plus the math foundations in the name.

  • Red flagMath practice and math in questions. There is no surface for the student to work a problem in notation, and review and exam questions are plain text with no way to present vectors, matrices or probability formulas properly. Whether the chat renders LaTeX is unverified. Tutor illustrations cover graphs, and the Python editor handles numeric demos, but the notation gap has no good answer today.
  • GuidelineNumeric answers are MCQ or open text. Write rubrics that score method and final value separately. Coordinate the notation approach with the math group.
AI102

Fundamentals of Machine Learning

SWE core · Term 74 credits · 4 unitsNeeded by 15 Feb 2027

Catalog commits to: what machine learning is, types of ML, the ML workflow, defining and framing ML problems, data collection and understanding.

  • GuidelineThe Python editor has no numpy, pandas or scikit-learn. All hands-on ML is external learning in VS Code, in the project lane. The editor is for pure-Python drills only.
  • GuidelineCharts and datasets live outside. The editor returns console output only. Students print summaries and paste them; the tutor draws the illustration. Supply datasets by URL in teaching instructions.
AI103

Prompt Engineering & Working with LLMs

SWE core · Term 84 credits · 4 unitsNeeded by 22 Mar 2027

Catalog commits to: what LLMs are, evolution of language models, transformer architecture basics, pretraining, fine-tuning and transfer learning, overview of major LLMs, prompt engineering.

  • GuidelineStudents use free-tier API keys, mainly Google Gemini and Groq. The syllabus is shared by the whole cohort, so no key can live in it; each student creates their own free account and key. Both providers offer an OpenAI-compatible endpoint, so one request shape covers both, and free-tier rate limits are enough for coursework. Re-verify the free tiers before shipping, and name Ollama as the offline fallback.
  • GuidelinePrompting technique needs no key. The tutor role-plays a model in chat. Only the parameter experiments (temperature, system prompts, structured output) need real calls, done in VS Code.
  • GuidelineOpen the API unit with a setup lesson: create the Gemini or Groq account, generate the key, store it in an environment variable, make one call. Add a tutor instruction to refuse pasted keys and tell the student to rotate them.
AI104

Applied AI Capstone Project (AI-Powered Full-Stack Application)

SWE project · Term 95 credits · 4 unitsNeeded by 7 Jun 2027

Catalog commits to: defining AI project scope and objectives, technology stack and architecture review, dataset and model selection, roadmap and milestones, integrating the selected AI model or LLM into a full-stack application. Prerequisites AI103, BE106, FE103.

  • Red flagNo project submission. Same as BE106 and FE103. The capstone is the whole course, so the timed-exam link workaround fits worst here. Submission is repo plus demo video showing the model or LLM integration working in the deployed app; students already recorded demos in CD102.
  • GuidelineAPI key: the free-tier Gemini or Groq key from AI103, set up again in the capstone's first project step.
  • GuidelineWrite it last. It reuses the BE106 and FE103 project conventions and the AI103 setup lesson. The catalog name binds it to a full-stack app with an integrated model. Model work is in VS Code, since the Python editor has no ML libraries.
  • GuidelineDemo and presentation in Google Slides, outline pasted back, deck on a discussion-board slot.

3 · Math foundations

2 courses · ≈ 60 lessons · first deadline 1 Feb 2027
MATH200 College MathematicsMATH110 College Algebra & Trigonometry

Why together. Both hit the same wall: no surface for practising math in notation, and no way to present notation in questions. It is red-flagged on each, and this author owns whatever partial answer is found and shares it with the AI101 author. Spans both programs, which is fine because the problem is the platform, not the subject. Two gen-ed courses is a light load; this author can take a course from group 7.

MATH200

College Mathematics

SWE gen-ed · Term 74 credits · 2 unitsNeeded by 1 Feb 2027

Catalog commits to: whole numbers, fractions, mixed numbers, decimals, ratio, rate, proportions, percentages, measurements, introduction to probability and statistics.

  • GuidelineTen catalog topics in a 2-unit shape (about 17–20 lessons). Every one must map to an outcome, so plan roughly two lessons per topic and use Challenge lessons to combine them.
  • Red flagMath practice and math in questions. Fractions, mixed numbers and proportions need to be written and read as notation, and neither the practice surface nor the question format supports that today. The spreadsheet plugin covers percentages, rates and basic statistics, which limits the damage but does not close the gap.
MATH110

College Algebra & Trigonometry

Business gen-ed · Term 66 credits · 5 unitsNeeded by 22 Feb 2027

Catalog commits to: algebra, trigonometry, functions, and business applications essential for quantitative analysis.

  • Red flagMath practice and math in questions, and this is the course it hurts most. Trig identities, function notation and graphs cannot be worked by the student or presented in a question with today's surfaces. Lean on the business-applications angle, where the spreadsheet carries the work, but the core algebra and trigonometry has no good home.
  • GuidelineBusiness 5-unit shape means about 40 lessons for four catalog topics. Plenty of room; keep each lesson to one concept.

CD102

AI Project Portfolio Development

SWE career · Term 83 credits · shape TBDNeeded by 19 Apr 2027

Catalog commits to: selecting, documenting and presenting AI projects, case studies showing technical skill and business impact, a professional portfolio website, project demonstrations, culminating in a complete portfolio.

  • Red flagNo project submission. The catalog says the course "culminates in a complete portfolio", so the portfolio is the deliverable, and today it can only be graded as a link pasted into the final exam. Case-study write-ups are canvas-editor work assessed as open text; the portfolio site is one page in the web editor, deployed outside if the student wants, and its link also goes on a discussion-board slot.
  • GuidelineThe tutor does not remember the student's earlier projects. Each lesson asks the student to describe the project they are documenting before working on it.
  • GuidelineDemonstrations are screen-recorded demo videos, scripted in Google Slides and coached from the pasted outline. This is where students learn the recording format that AI104 and CAPS300 submit.
  • GuidelinePick the 3-credit shape (full 4-unit or reduced) before writing, and use it for CD103 and CD104 too.
CD103

AI Career Strategy and Interview Preparation

SWE career · Term 93 credits · shape TBDNot yet scheduled

Catalog commits to: job search strategies for AI roles, tailoring applications, technical and behavioral interview preparation, salary negotiation, mock interviews, coding challenges, a personalised career roadmap and interview strategy.

  • GuidelineMock interviews are tutor role-play in chat, text only. Coding challenges run in the Python editor. Both work well; name the interview format in teaching instructions so the tutor stays in role.
  • GuidelineCareer roadmap and tailored applications are canvas-editor documents. The student pastes the job posting into the lesson since the tutor cannot browse.
CD104

AI Career Launch Workshop

SWE career · Term 93 credits · shape TBDNot yet scheduled

Catalog commits to: guided hands-on job search, actively applying to AI positions with instructor guidance, real-time interview feedback sessions, networking events and industry connections, personalised coaching, a supported transition to employment.

  • Red flagThe catalog promises humans and events. Instructor guidance, live feedback, networking events and personal coaching are not things a chat tutor can deliver, and a workshop about applying to jobs has almost no mastery outcomes to write. Either run a human-led component alongside and say so in the syllabus, or amend the catalog. Do not start this course until that is decided.
  • GuidelineWhat the tutor can do: review applications the student pastes, run practice interviews, track a weekly application plan in canvas-editor. Build the Maestro half around that.

CAPS300

Applied Business Capstone Project

Business capstone · Term 96 credits · 5 unitsNeeded by 6 Dec 2027

Catalog commits to: integrating all program knowledge through independent research, practical case analysis, and comprehensive business solution development. Prerequisite: every course except PHIL110, PSYC140, COMM180.

  • Red flagNo project submission. The business plan and deck can only be graded as a link pasted into the final exam and checked manually.
