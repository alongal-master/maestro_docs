git-terminal plugin — input playground

A stateful plugin. It starts from inputs, the learner edits that state by typing commands (or by editing files in the right rail), and submit() returns the whole session back to the host. The returned JSON is itself a valid inputs.resume value — submit, click "load submission as resume", and the session comes back verbatim. Everything is in-memory: no real filesystem, no network.
