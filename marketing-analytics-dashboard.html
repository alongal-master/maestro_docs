marketing-analytics plugin — input playground

A view-only plugin — it only ever renders inputs.dataset, nothing is bundled inside it and nothing gets submitted back. Pick a fixture to load its full JSON into the editable box below, edit anything, and click Launch. Data is always plotted one point per entry in dataset.weeks. Above each chart, inputs.metrics can override a metric's definition/formula and attach a target (e.g. "CAC ≤ $35") — shown as a badge and a dashed reference line on the chart itself.
