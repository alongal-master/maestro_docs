math-visual plugin — input playground

A view-only plugin declared in a lesson's requiredPlugins, but rendered inline inside the tutor's chat message — not in the right side panel, and with no toggle that opens it. The tutor never supplies a computed value: it declares expressions, defining coordinates and raw data, and every number on screen — angle measures, intersections, tangent slopes, Riemann totals, integrals, regression coefficients — is computed by JSXGraph at render time. Anything the tutor asserts that the library can check gets checked, and a declaration that can't be true renders an error card rather than a plausible wrong picture. Sliders and draggable points are live; nothing is ever submitted back.
